## API Routes

| Method | Route          | Description     |
| ------ | -------------- | --------------- |
| GET    | `/events`      | Get all events  |
| GET    | `/events/{id}` | Get one event   |
| POST   | `/events`      | Create an event |
| PUT    | `/events/{id}` | Update an event |
| DELETE | `/events/{id}` | Delete an event |
